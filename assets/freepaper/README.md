# FREE PAPER PDF管理

各号のPDFは `no01/`、`no02/` のようなフォルダーへ、`color01.pdf`、`color02.pdf`、`color03.pdf` の名前でコピーします。元データは変更しません。未準備の号に仮PDFは置きません。

## 号の追加

1. `assets/js/archive-data.js` の `ARCHIVE_ITEMS` にタイトル・ID・詳細ページURLを登録します。発行年月は `ARCHIVE_FACTS`、表裏WebPは `detailImages` で管理します。
2. PDF3種類を `assets/freepaper/noNN/` にコピーします。
3. 同ファイルの `FREE_PAPERS` に号数 `number`、3つの `pdfs`、`downloadName: 'SAWARABAN_noNN.pdf'` を登録します。PDFパスは `archive-data.js` からの相対パスです。
4. 新しい号の場合は既存の詳細HTMLを複製し、タイトルと `data-archive-detail` を登録IDに合わせます。

no.2／no.3は既にデータと詳細ページがあるため、PDFのコピーと `pdfs` 配列の登録だけで有効になります。空配列や3件未満ではボタンを表示しません。ダウンロード処理自体の変更は不要です。

各クリックで `Math.floor(Math.random()*3)` により独立に抽選し、同一オリジンのPDFリンクの `download` 属性で共通の保存名を指定します。画面への抽選結果表示・別タブ・ページ遷移はありません。保存ダイアログなどの最終動作はブラウザー設定に従います。

## ローカル確認

`npm run dev` で起動後、`node scripts/check-freepaper-download.cjs` を実行します（Chromeが必要）。PC幅・モバイル相当のタッチ操作で3種類を個別に選択し、保存名・元PDFとのバイト一致・ページ維持・プレビュー・未登録号の非表示・抽選区間・実乱数の分布を確認します。

今回のPDF3種類はHドライブの指定元とのSHA-256一致を確認済みです。PDF専用の解析／描画ツールがローカル環境にないため、PDF自体の全ページ表示は未確認です。公開後のGitHub Pages配信と実機スマートフォンの確認も未実施です。
