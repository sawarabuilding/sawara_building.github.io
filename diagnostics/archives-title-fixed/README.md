# ARCHIVES題字：左側の固定回転表示を有効化

プレビュー：http://127.0.0.1:4173/archives/

## 原因と修正

前回は `.archive-typeface-ready` が付いた場合だけ縦配置するCSSでした。
`archive-title.js` がフォントURL未登録時に処理を終了したため、そのクラスが付かず、共通CSSの横向き表示が残っていました。
今回、フォント読み込みの成否と配置を完全に切り離しました。

- `archives/index.html`：既存の題字リンクを専用 `.archive-title-rail` に入れました。文字列は一つだけで、複製していません。
- `assets/css/archive-index.css`：フォント準備クラスの条件を撤去し、一覧の題字に常時適用。固定コンテナ内で `rotate(-90deg)` を指定。共通CSS・モバイルCSSのdisplay、margin、font-size、最小高さなどを一覧専用セレクターで明示的に整理。
- `assets/js/archive-title.js`：画面高さに収まる文字サイズ調整を先に実行。フォントがなくても固定・回転・先頭リンクは機能します。利用可能な正規フォントURLの登録は任意です。
- `scripts/check-archives-title-fixed.cjs` と本フォルダー：実ブラウザの検証とスクリーンショット。

題字は黒背景、透明の塗り、白1.2pxの輪郭、一行の文字列全体を-90度回転。
固定レールは左24px・幅60px・高さ100dvhで、実際の文字はPCで左端20〜90pxの範囲に収まります。
書体は既存Arial系を維持。Eurostile Extended Blackは未提供ですが、これを理由に縦配置を停止しません。
左右・上下の文字変形はなく、必要時のみフォントサイズを調整します。

題字の領域だけを作品群の左余白に確保し、PCでは既存の列間余白で調整して項目幅を維持。
各項目の内容・順番・分類・書体・リンク・配置のオフセットと表紙画像は変更していません。
右上ロゴと個別ページ、3Dトップは変更なしです。

## 実ブラウザ検証

Chromeでキャッシュを無効化して読み込み、1366×768・1440×900・1920×1080・820×1180・390×844・375×667・844×390で確認しました。

- 題字リンクは一つのみ。画面上部に横向きの題字なし。
- computed styleのtransformは全サイズで `matrix(0, -1, 1, 0, 0, 0)`。
- レールのcomputed positionはfixed。
- 文字の塗りはtransparent、輪郭は白1.2px、一行・横組のまま回転。
- 文字列全体が画面内、中心Yは画面高の50％。左側レールと作品群は非接触。
- スクロール前後の題字座標が一致。クリックでscrollY=0へ復帰。
- ホバーで白く塗られ、離すと輪郭表示へ復帰。Enterでも先頭移動が可能。
- ロゴのサイズ・画像上端・右余白は従来値と一致。
- JavaScript無効でも基本の-90度回転を確認。
- データ、表紙、共通CSS、既存個別HTMLのハッシュ一致。JS例外なし。
