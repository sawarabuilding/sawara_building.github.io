## モデルの扱いと未確定事項

元OBJ・MTL・GLBは保持しています。別ファイル`assets/models/sawara-building-web.glb`を制作しました。
遠方の`object_332`だけを除外。水平中心を原点へ移動し、地盤の高さZ=0を保持しています。
寸法・頂点の相対配置を変えず、グループ・材質単位でメッシュを統合。5,228→12メッシュ、433,318→433,290三角形（除外分28三角形）。
容量は15,855,164→15,775,420バイト。今回は描画呼び出しの削減を優先し、非可逆な簡略化や圧縮は未実施です。

元OBJのグループ`RC_`、`RC__`、`RC___`をRC構造の命名としてコンクリートに対応。
ガラスは元の「ガラス」材質に対応。透明度0.2、微かな青緑、控えめな透過に変更しています。
他の4,951部材は木・コンクリートと断定できず、Web用コピーでも元の材質を維持しています。
変更・未分類の元オブジェクト一覧は`preparation.json`に記録。
木材への割り当ては行っていません。RC分類も作成者による確認が必要です。
作成者から木材の正しいレイヤー名は「木」「木建具」「木家具」と回答を受けています。
現在のOBJでは日本語グループ名が`_`や`___`等になっており、部材との対応を確定できません。
元の.3dmまたはレイヤー名を保持した再出力OBJが必要です。

初期画面の「単色の形状確認表示」は、材質分類とは独立した表示用オーバーライドです。
元の材質を保存したまま全形状を読みやすくするためのもので、「Web用コピーの材質表示」に切り替えられます。
完成素材の全面適用は、木材・未分類部材の確認後に行います。

## 断面と階の対応

長手方向を横に見るカメラ（Blenderの-X側／Three.jsでも-X側）を使用。
地上モデルはWebGLのクリッピング平面X=-0.8mで表示上だけ切断します。GLB本体を切り刻む処理はしません。
切断専用の面を追加するキャップ処理は未実施です。厚みのある床・壁の既存形状を使用しています。
地下の3D形状は制作していません。

元モデルの床らしき高さは約2.73m間隔。HPの5テナントと物理的な階の正確な対応は未確認です。
`floors.js`の`modelRange`は暫定的な選択帯で、5Fは上部の広い範囲を含みます。
この暫定対応を実建物の確定した階構成として扱わないでください。
