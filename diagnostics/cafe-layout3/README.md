- 写真5枚すべてが幅・高さとも140％、中心位置は不変。回転0度・縦横比不変。

- 表は画面の水平・垂直中央。スクロールしても初期表の位置は固定。
- ロゴ・左上表示の位置は前後一致。MENUの開閉、屋号で復帰、ロゴから3Dトップへ移動が正常。
