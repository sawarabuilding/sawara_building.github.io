# 模型底面のメッセージ

外観モデルの最低位置にある水平三角形を確認し、土台裏側の中心に「友だちにならないか」を追加しました。
GLBは上書きしていません。文字はCanvasTextureで生成し、外観モデルの子要素として配置しています。

- 白 #FFFFFF、游ゴシック優先、700、改行なし。フォールバックはNoto Sans JP。
- 日本語フォントの読み込み後に描画。文字本体の幅は土台幅の65％。
- 土台最下面Y=-1mに対し文字面Y=-1.003m。3mm離して表示干渉を回避。
- 下向き片面のMeshBasicMaterial。照明・トーンマッピングの影響を受けず、深度判定は有効。
- 元の模型寸法・中心・カメラのフィット計算は変更なし。断面モデルには文字を追加していません。

## 変更ファイル

- `assets/js/underside-label.js`（新設）：底面検出とCanvasTexture生成。
- `assets/js/building.js`：外観モデル読み込み時に文字面を追加。
- `scripts/check-underside.cjs`（新設）：表示・非表示とモデル保全の検証。
- 本フォルダー：結果と画面。
