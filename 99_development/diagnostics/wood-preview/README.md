# Rhino元レイヤーに基づく木材の反映

2026-11-03。指定されたRhino .3dmを読み取り専用で解析しました。
Hドライブの元データとローカル解析用コピーのSHA-256は一致しています。
元ファイルの保存・変更・再出力は行っていません。
元データの全レイヤー・図面情報を含む解析中間ファイルと.3dmコピーは、Git対象外の`.local-cache/`と`.local-backups/`に保存しています。

## 部材の対応付け

確認できたレイヤー名は「木」「木建具」「木家具」です。
既存OBJのグループ名がこれらの日本語名をアンダースコアにした表記と一致し、かつ
Rhinoの部材と既存GLBのバウンディングボックスの最小・最大XYZ、全6値が1mm以内で一致するものを照合しました。
複数候補がある場合もすべての候補が同一レイヤーのときだけ採用しています。
近隣にあるという理由や形状の見た目だけでは割り当てていません。

| Rhinoレイヤー | 対応できたGLB部材数 |
| --- | ---: |
| 木 | 2,671 |
| 木建具 | 1,059 |
| 木家具 | 302 |
| 合計 | 4,032 |

全体では5,062部材のレイヤーを照合。照合できない166部材があり、今回そこへ木材を追加割り当てしていません。
照合後も、床・金属・石・竹などを木材やコンクリートへ一律に置き換えていません。
元の形状・寸法を維持した既存GLBを材料として使い、形状を元Rhinoから再メッシュ化していません。
対応表と根拠は`../rhino-layer-matches.json`に記録しています。

## 新しいWeb用コピー

`assets/models/sawara-building-web-wood.glb`を新規作成しました。
元OBJ・MTL・変換元GLB・前回のWeb用GLBは上書きしません。

コンクリート・ガラスの設定、遠方オブジェクトの除外、中心の調整は前回のWeb用コピーと同じです。
容量15,508,988バイト（約15.51MB）、14メッシュ、433,290三角形。
Blender再読み込みで寸法約15.00×18.67×18.08mと三角形数の一致を確認しました。
材質を追加割り当てしていない919部材は元の材質を維持しています。
Webの初期表示を木材反映版へ切り替え、以前の単色表示も切り替え操作で利用できます。
