# カフェ：白背景・中央罫線表・指定写真

プレビュー： http://127.0.0.1:4173/cafe/

## 実装

- 背景 #FFFFFF、中央表の文字・罫線 #000000。
- 上部はKITCHEN FLAMINGOとMENUの2段。下部は1列8マス、追加リンク・ホバー演出なし。
- 店名クリックで初期画面、MENU・既存About／Contactは従来のパネルを表示。新しいページやリンク先は作成していません。
- 初期表は画面中央固定。下部の項目間隔は均等、罫線は全幅1px。
- 参考掲載画像の表の幅139：高さ370を基準に外形比を設定。上部3段分の高さを2段に配分しました。
- PCでは従来の左ナビ・右本文。スマートフォンでは長い表の下に本文を置き、ページスクロールで読める構成です。
- 指定写真を `cafe/assets/images/000016.jpg` に無編集コピー。背景5枠で共用し、従来の表示幅の125％、回転0度、縦横比維持・画像のクロップなし。
- 中央表を不透明な白で描画し、写真が背後に来ても文字・罫線の可読性を維持。
- 元のHドライブ写真、旧SVG、3Dモデル、ARCHIVESページ、完成版ブランチは変更していません。コミット・push・公開なし。

掲載画像は2018年の紹介画像で、下部末尾には旧表記があります。今回は現行英語版の8項目を優先しています。
参考サイトの写真・イラスト・ロゴはサイトにコピーしていません。

## 検証

1440×900、1366×768、820×1180、390×844、375×667で確認。
白背景・黒文字、上2段＋下8マス、外形比・中央固定、写真の比率と回転0度・125％表示を実測。
MENU／About／Contactの切り替え、店名での復帰、右上ロゴから3Dトップへのリンク、横方向のレイアウトを確認。
画像は元ファイルとSHA-256一致（1,281,444 bytes）。JS例外・ローカルHTTPエラーなし。
