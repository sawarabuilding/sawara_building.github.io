## 実装

- archives/index.html: Archivo Blackの先読み。
- assets/css/archive-index.css: 一覧だけに適用する字体・題字・画像・ホバー設定。題字は固定・-90度・白輪郭1.2px。作品は58%黒オーバーレイと中央の白い太字、0.3秒。
- assets/js/archive-title.js: 実測文字幅から画面高さ87.5%に合わせる。字形の変形なし。
- assets/js/archive-data.js: 表紙・イベント写真とホバー題名の設定。既存項目名・分類・順序・リンク・配置設定は維持。詳細ページ用imageは変更しない。
- assets/js/archives.js: 画像と独立オーバーレイの生成。画像のない項目も既存位置に領域を確保し、ホバー・キーボードフォーカスで題名表示。タッチは1回目で題名、2回目で既存の詳細へ移動。
- assets/fonts/archivo-black/: 正規Google Fonts配布のArchivo Black、OFLと配布元記録を同梱。

通常時の作品タイトル・分類は視覚的に非表示にし、支援技術用のラベルは維持した。作品の異なる大きさ・既存の不規則なオフセットを保っている。共通archives.css、個別ページ、3Dトップ、カフェには今回変更を加えていない。
