# B1断面・トップページ改修結果

2026-11-03。採用断面はユーザーが指定したB1（元Rhinoの-Y側から+Y側を見る方向）。
B1は断面候補の名称で、地下B1Fの3Dモデルを意味しません。
元Rhinoの「断面」レイヤーのAではなく、確認図のBを採用しています。
指定の参考画像を読み取り、空・地面・切断面・素材の色調と余白の基準として使用しました。
参考画像そのものをサイト背景へ流用したり、描かれた植栽や家具を追加したりしていません。

## 切断モデル

派生モデルを別ファイルで作成しました。

| ファイル | サイズ | 三角形数 |
| --- | ---: | ---: |
| `assets/models/sawara-building-exterior-v2.glb` | 15,722,352 B | 433,290 |
| `assets/models/sawara-building-section-b1.glb` | 13,694,716 B | 402,362 |

切断位置は元Rhino座標Y=11,770.959mm、Web座標Z=+0.121666m。
BlenderのYがこの値以上の側を残し、切断した壁・床の閉じた輪郭に130面の濃いチャコールのキャップを追加しました。
閉じたソリッドを切れるよう、GLBの法線・UV境界で分離された同一座標の頂点を派生モデルで接続しました。
壁厚・階高・家具や階段の位置を編集したり、未照合部材の素材を推測で変更したりしていません。
元Rhino・OBJ・MTL・変換元GLB・前回の木材反映版のハッシュを照合し、変更がないことを確認しています。
外観の全体寸法は約15.00×18.67×18.08mのままです。

## 素材・背景

- コンクリート: 青みを含むグレー、粗さ0.96。256pxのノーマルとわずかな顔料ムラ。
- 木: #B39D7D、粗さ0.9、控えめな256pxの木目ノーマル。確認済み木材レイヤー由来の部材だけに適用。
- ガラス: Alpha 0.12、粗さ0.13。Webで透明ブレンド・depthWrite無効・単一パスを指定。
- 空: 淡いブルーグレーとごく薄い紙のノイズ。
- 地面: #171819。1F床上端0.10mを毎フレーム投影し、同じ位置に水平境界を表示。
- 地下室などの新しい3D形状は制作していません。
- 日本語フォントはGoogle FontsのNoto Sans JPへ変更。

以前の生成ノーマル画像は黒く保存されていたため、元ファイルを保持したまま、正しいRGBノーマルPNGを新規生成しました。
新しい画像はGLBにも埋め込んでいます。元の黒い画像を上書きしていません。

## 床高さとナビゲーション

Rhinoの床部材の上端を採用: 1F=0.10m、2F=2.83m、3F=5.56m、4F=8.29m、5F=11.02m。
1F〜4Fの対応は元の平面cutレイヤーと照合。5Fはその次の実在する主要床に対応させています。
ラベルはこの値に設定可能な読みやすさ用オフセットを加え、カメラで画面座標へ投影します。CSSの等分配置ではありません。
テナント名称とURLは`assets/js/floors.js`、ラベルやARCHIVESの配置は`assets/js/scene-layout.js`で変更できます。

外観ではホイールでズーム、右ドラッグで回転。クリック／タップで案内へ移動。
案内ではホイール上で上階、下で地下へ移動。矢印キー・PageUp/Down・タッチスワイプ・階数ボタンにも対応。
階名はURLが設定されている場合だけリンク化します。未制作のテナントページはURL=nullとして、存在しない個別ページへのリンクを生成していません。
地下の既存リンク先は資料未登録の準備ページです。B1F刊行物一覧は引き続き未制作です。

## アニメーション・検証

カメラはクリック時の位置から球面上を滑らかに移動し、建物を突き抜ける直線移動を避けています。
約1.8秒で黒から空へ、外観から実切断モデルへ変化。階表示とARCHIVESも同時にフェードします。
案内への通常入場時は1Fを選択。戻る操作で元の観察方向へ戻り、自動回転と自由操作を再開します。
動きを減らす設定では自動回転を止め、切り替えアニメーションを省略します。
切り替え時のシェーダーとテクスチャは事前準備します。

`browser-validation.json`にChromeの操作検証・アニメーション実測・画面寸法を記録しています。
最終検証は23項目通過。通常表示のJavaScript・通信エラーは0件、非軽減時の切り替え時間は約1.81〜1.92秒でした。
`model-validation.json`に両GLBの再読み込みと元データのハッシュ照合結果を保存。
スマートフォンはChromeでの画面幅・タッチ入力のエミュレーションで、実機検証ではありません。
