## 元Rhinoから見つかった根拠

元データの読み取り専用コピーの解析結果を使用しました。
`断面`レイヤーに1つのSurfaceがあり、X座標の最小・最大がともに20,430.14863893253mmでした。
元オブジェクトIDは`6fdf479a-b0c9-4779-b756-48fa6f4b1be2`です。
これはX一定の断面平面で、中央の45度回転した吹抜の向かい合う頂点を結ぶ位置にあります。
平面図の赤線Aがこの既存断面平面です。

Web用コピーでは水平中心を移動しているため、同じ切断面はX=+0.657710mに相当します。
現在のWeb表示のX=-0.8m（元座標X=18,972.438526mm）は、この平面から約1.458mずれています。
カメラだけを45度回す問題ではなく、切断面自体の位置の違いです。
