# 断面パースの表記・ロゴ調整

プレビュー： http://127.0.0.1:4173/ → CONTENTS。

## 変更ファイル

- `assets/css/style.css`：ARCHIVESを-90度から0度へ（時計回り90度）変更。文字サイズ・フォント・色は維持し、黒い地面の左側に横書きで表示。
- 同CSS：断面の日本語見出しに外観と同一の游明朝／Noto Serif JP設定を適用。断面側の文字サイズ・色・左位置は維持。
- `assets/js/floors.js`：5F「うんち」、4F「ARCHITECTURE」、3F「CAMERA PHOTOGRAPH」、2F「LIBRARY」、1F「CAFE BIKE」。旧二段用の英語フィールドは地上階から撤去。床高さ・選択範囲・URLは変更なし。
- `assets/js/directory.js`：二段目の英語要素を撤去し、一階につき名称ひとつに統一。登録済みの1Fリンクは維持。
- `assets/css/building-logo.css`（追加）：カフェと断面で使うロゴ位置・サイズの共通CSS。既存カフェの値をそのまま移動。
- `index.html`：断面専用の右上ロゴを追加。クリック・タップで `./index.html` へ戻る。既存タッチリンクのヘルパーを使用し、3D操作と分離。
- `cafe/cafe.css`：ロゴの既存指定を共通CSSへ参照化。見た目は変更なし。
- `scripts/check-guide-labels.cjs`、本フォルダー：確認スクリプト・画面・記録。

地上階は従来の英語表記と同じArial系の書体を基本に、一行で表示。
PCの階ラベルの位置・横線、1Fの選択色を維持。スマートフォンでは長い名称が画面からはみ出さない範囲で文字列の左端余白を補正し、床高さに対応する縦位置は維持しています。
ロゴはカフェ／ARCHIVESと同一の画像・表示寸法・座標です（PC画像70×70、上端43px・右4vw、モバイル44×56、上端29px・右5vw）。
